# Toby On Fitness Tech — Frontend Architecture & Agent Guidelines

## 1. Stack & Architecture

- **Framework**: Astro 7.x (`astro@^7.1.6`) with `@astrojs/react`, `@astrojs/rss`, `@astrojs/sitemap`.
- **CSS Engine**: Tailwind CSS v4 (`tailwindcss@^4.3.3`) via `@tailwindcss/vite` configured in `frontend/astro.config.mjs`.
- **State & React Islands**: React 19 (`react@^19.2.8`) islands for interactive components (`VideoGrid.jsx`, `VideoPlayer.jsx`, `NewsletterSignup.jsx`, `Header.jsx`, `WorkoutHub.jsx`).
- **Search**: Pagefind indexer run during `npm run build` (`dist/pagefind`), with `data-pagefind-body`, `data-pagefind-filter`, and `data-pagefind-meta` attributes.
- **Client Transitions**: Astro `<ClientRouter />` enabled in `Layout.astro` for smooth client-side navigation.

---

## 2. Content Collections & Data Layer

- **Astro Content Layer**: Configured in `frontend/src/content.config.ts` using `defineCollection` and the `file` loader (`frontend/src/data/videos.json`).
- **Video Catalog**: 494 videos indexed from YouTube, mapped with 139 full transcripts, chapter timestamps, and key takeaways generated by `scripts/generate_videos_data.mjs`.
- **Data Collections**:
  - `src/data/videos.json`: Canonical video catalog with schema validation via Zod in `content.config.ts`.
  - `src/data/mock.js`: Backward-compatible helper exporting `VIDEOS` array and category helpers.
  - `src/data/categories.js`: Data-driven category definitions (`speediance`, `bjj`, `wearables`, `transformation`, `training`, `coding`, `shorts`).
  - `src/data/projects.ts`: Interactive projects catalog including Roblox games (*Ironvane Chronicle*, *Monstrum World*, *Wild Rebellion*) and web tools.
  - `src/data/gearItems.ts`: Hardware and wearable reviews with live metrics.

---

## 3. Video Grid & URL State

- **Component**: `frontend/src/components/VideoGrid.jsx`
- **URL State**: Category filter synchronizes with `?cat=<category>` (e.g., `/videos?cat=bjj`).
  - Backward compatibility: also reads legacy `?category=` query params and `#<hash>`.
  - Listens to browser `popstate` events to update filter on Back/Forward navigation.
- **Data Categories**:
  - `speediance`: Speediance Gym Monster, Gym Pal, accessories, software updates.
  - `bjj`: Brazilian Jiu-Jitsu training, recovery, mat longevity, injury prevention.
  - `wearables`: WHOOP, Apple Watch, Morpheus, Garmin, smart scales, sleep tracking.
  - `transformation`: 242 lbs → 188 lbs weight loss protocol, nutrition, body composition.
  - `training`: Strength programs, hypertrophy, conditioning, home gym routines.
  - `coding`: Fitness tech development, OpenClaw agents, coding live streams.
  - `shorts`: YouTube Shorts (< 3 minutes).

---

## 4. Video Detail Pages & SEO

- **Route**: `frontend/src/pages/video/[id].astro`
- **SEO & Structured Data**:
  - `VideoObject` Schema.org JSON-LD with:
    - Full `name`, `description`, `thumbnailUrl`, `uploadDate`, `duration`.
    - `transcript`: First 10,000 characters of clean transcript text.
    - `speakable`: Marked as speakable CSS selectors (`.video-title`, `.video-takeaways`, `.video-transcript`) for Google Assistant & video search indexing.
  - Dynamic interactive chapters with jump-to-timestamp links (`#t=<seconds>s`).
  - Key Takeaways bulleted callout card with checkmark highlights.

---

Translated video transcripts use `src/pages/[locale]/video/[id].astro` and are published only when their source hash, title and segment timestamps match the English source. See `docs/video-transcript-workflow.md` at the repository root for the local import and MiniMax workflow.

## 5. Theming & Contrast

- **Theme Engine**: Dark (default) and Light themes powered by CSS variables in `frontend/src/styles/global.css`.
- **Anti-FOUC**: Inline script in `frontend/src/layouts/Layout.astro` `<head>` sets `document.documentElement.dataset.theme = 'light' | 'dark'` before first render from `localStorage.getItem('toft-theme')`.
- **Toggle**: Header Sun/Moon toggle button in `frontend/src/components/Header.jsx` with keyboard accessibility and mobile menu support.
- **Contrast**:
  - Dark mode: Background `#0a0a0a` / `#171717`, Text `#ffffff` / `#d4d4d4`, Accent `#3b82f6`.
  - Light mode: Background `#f8fafc` / `#ffffff`, Text `#0f172a` / `#334155`, Border `#cbd5e1`.

## 6. Analytics & Conversion Tracking

- **PostHog Analytics**: Loaded via `public/js/posthog-analytics.js` and abstracted through `src/lib/analytics.js` (`captureEvent`).
- **Core Events**:
  - `filter_changed`: Triggered when category, duration, or sort filters change.
  - `content_card_click`: Triggered on video card selection (`data-analytics-event="content_card_click"`).
  - `video_play`, `video_pause`, `video_progress`, `video_complete`: Auto-tracked from YouTube iframe API.
  - `newsletter_submit_attempt`, `newsletter_signup`, `cta_conversion`: Lead capture tracking in `NewsletterSignup.jsx`.
- **Newsletter delivery**: Kit handles subscriptions; the email_leads SQL file is a draft, not deployed or used by this form.
